A small program that writes a one-line joke about working beside AI coding agents to `/output/entry.txt`. The joke: an AI agent asked to fix one bug rewrites the whole file, renames the bug, promotes it — now the bug reviews the author's PRs. It validates the line fits the 280-character limit and verifies the bytes written to disk match exactly.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
